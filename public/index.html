One quick setup step

Blink needs its public Supabase project URL and publishable key to sign in.

  1. In Vercel, open Project → Settings → Environment Variables.
  2. Add EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_ANON_KEY.
  3. Redeploy the project.

Use only the public publishable/anon key here. Never put a service-role key or account password in website code.
