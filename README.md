# Blink

A close-friends social app MVP built with React Native and Expo.

## Features

- Stories carousel
- Personal story upload entry
- Social feed
- Friend avatars and post metadata
- Likes and replies
- Mobile-style navigation

## Run locally

```bash
npm install
npm start
```

Then scan the QR code with Expo Go or press:

- `a` for Android
- `i` for iOS
- `w` for web
